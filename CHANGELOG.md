# Changelog

Пользовательские описания релизов. Именно ЭТОТ файл (не заголовки коммитов) показывается в уведомлении об обновлении: раздел на версию, пункты — строки, начинающиеся с «- ». Заполняется ПЕРЕД тегированием релиза — scripts/release.sh откажется публиковать версию без её раздела здесь. Коммиты остаются техническими и пользователям не показываются.

## 0.5.1 — 2026-09-05

- Fail2ban при установке: исправлена мёртвая тюрьма sshd из 0.5.0 — ставится python3-systemd (без него backend systemd не стартует), успех проверяется по самой тюрьме, а не по службе; если Fail2ban уже стоял без модуля — доставит и перезапустит

## 0.5.0 — 2026-09-05

- Лицензия: код открыт под GNU AGPL-3.0 (файл LICENSE, раздел в README). Закрытое коммерческое использование — по отдельной лицензии; правообладатель Zergont
- Защита сервера: install.sh предлагает поставить Fail2ban (по умолчанию — да) — бан подбора пароля по SSH, IP вашей сессии установки в белом списке, работает и на минимальных Ubuntu без auth.log
